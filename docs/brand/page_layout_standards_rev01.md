# WNYHS Page Layout Standards — REV01

Status: LOCKED (governance standard)
Context: CTX-WNYHS-FINISH-LINE-REV01

## 1. Homepage Layout Order (Locked; reconciled by HOMEAUTH001)

The homepage section order is:
1. hero
2. core promise
3. six pillars
4. why WNY
5. how customization works
6. real-life outcomes
7. expandable system
8. education
9. existing-customer path
10. primary CTA / footer transition

This replacement-homepage-only sequence was explicitly authorized by HOMEAUTH001. Detailed section, visual, terminology, claims, asset, mobile, and implementation requirements are controlled by:

`docs/site-architecture/HOMEAUTH001_WNYHS_HOMEPAGE_VISUAL_AUTHORITY_REV01.md`

This amendment does not change interior-page layout, responsive, spacing, accessibility, semantic-token, or component-behavior authority.

## 2. Visual Rhythm Rules

Apply:
- premium restraint
- no app-shell/tiny boxed-page feel
- no excessive nested borders
- calm CTA hierarchy

## 3. Typography Rules

Apply:
- restrained display headline use
- readable body copy
- no overuse of giant headline treatment

## 4. Page Consistency Rules

Public WNYHS pages must:
- feel like one coherent site
- avoid random one-off layouts unless a task explicitly scopes that exception
